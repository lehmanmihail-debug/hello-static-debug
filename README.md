# 🌤️ Weather App (Hello Static)

Статический сайт с прогнозом погоды. Написан на чистом HTML, CSS и JavaScript. Автоматически деплоится на GitHub Pages через GitHub Actions.

## 🚀 Как пользоваться
1. Введите название города в поле ввода (например, **Москва** или **London**).
2. Нажмите кнопку **Узнать погоду** (или нажмите Enter).
3. Сайт покажет текущую температуру, погодные условия, скорость ветра и влажность.
4. Вы также можете воспользоваться кнопками быстрого выбора (Москва, СПб, Лондон).

*Примечание: при загрузке страницы автоматически показывается погода в Москве для демонстрации.*

## 🛠️ Локальный запуск
Так как проект без сборки, достаточно открыть `public/index.html` в браузере.
