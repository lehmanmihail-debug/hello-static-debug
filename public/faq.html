Откуда берутся данные о погоде?

Из открытого API Open-Meteo. Это бесплатный сервис для некоммерческого использования: он не требует регистрации и API-ключей. Мы отправляем запросы прямо из браузера — сервер не нужен.

Почему на главной показывается погода Москвы?

Это демо-режим: чтобы страница не встречала вас пустыми карточками, при загрузке мы автоматически показываем погоду Москвы. Просто введите свой город — и данные обновятся.

Какие города можно искать?

Любой населённый пункт мира! Страница «Прогноз на неделю» использует геокодинг Open-Meteo, который понимает русские и английские названия — например, «Казань» или «London». На странице «Города мира» уже собраны 9 крупнейших городов планеты.

Почему сайт написан без React и Vue?

Так задумано! Это учебный проект: цель команды — разобраться в основах веб-разработки, а не прятать логику за фреймворками. Всё, что вы видите на сайте, написано руками на HTML, CSS и JavaScript.

Как быстро сайт обновляется после изменений кода?

Автоматически! GitHub Actions собирает сайт и публикует его на GitHub Pages при каждом push в ветку main. Обычно обновление занимает одну-две минуты. Историю сборок можно посмотреть во вкладке Actions.

Как запустить проект у себя на компьютере?

Сборка не нужна: склонируйте репозиторий и откройте файл public/index.html в браузере. Для запуска линтеров выполните npm install, затем npm run lint.

Я нашёл баг — что делать?

Откройте issue в репозитории и опишите проблему: что сделали, что ожидали и что получилось. Команда разберётся и починит!
