Как запустить сайт у себя?
Просто откройте файл index.html двойным кликом — сайт откроется в браузере и будет полностью работать: темы, игры, формы. Можно и «по-взрослому»: запустить локальный сервер (python -m http.server) или расширение Live Server в VS Code, но это необязательно.
Нужен ли интернет для работы сайта?
Нет. Все данные — цитаты, факты, вопросы викторины, логика игр — лежат прямо в файлах проекта. Интернет нужен только если вы хотите посмотреть сайт на GitHub Pages или склонировать репозиторий.
Почему вы убрали прогноз погоды?
Раньше сайт ходил к внешнему API за прогнозом, но в некоторых сетях (учебные Wi-Fi, предпросмотр в редакторе) эти запросы блокировались — пользователи видели «Не удалось загрузить данные». Мы решили, что сайт, который всегда работает, лучше сайта с погодой, который иногда работает. Так родилась текущая концепция.
Как добавить новую страницу?
Скопируйте любую готовую страницу как шаблон, поменяйте содержимое блока <main>, отметьте свою вкладку классом active в навигации — и добавьте ссылку в меню на всех остальных страницах. Стили уже готовы: используйте классы card, stack-list, step-list.
Как изменения попадают на живой сайт?
Каждая задача делается в отдельной ветке, затем оформляется Pull Request. После ревью тимлида ветка вливается в main, и GitHub Actions автоматически собирает и публикует сайт на GitHub Pages. Статус сборки видно во вкладке Actions репозитория.
Что проверяют линтеры?
Три инструмента: ESLint следит за JavaScript (неиспользуемые переменные, устаревшие приёмы), Stylelint — за порядком в CSS, html-validate — за корректностью разметки. Все три должны проходить без ошибок перед вливанием PR.

Как с вами связаться?
Почта и Telegram — на странице «Контакты». Можно написать прямо из формы там же: она откроет ваш почтовый клиент с готовым письмом. Если хотите в команду — так и напишите, обсудим первую задачу.
