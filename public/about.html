Что это за проект

Weather App — учебный проект команды «Hello Static»: сайт с прогнозом погоды, написанный на чистом HTML, CSS и JavaScript. Мы сознательно отказались от фреймворков и сборщиков, чтобы понять, как веб работает «под капотом». Сайт автоматически собирается и публикуется на GitHub Pages при каждом изменении кода — это наш первый опыт настройки CI/CD.

Данные о погоде мы получаем из открытого сервиса Open-Meteo — это бесплатный API, который не требует регистрации и ключей. На сайте есть поиск по любому городу мира, прогноз на неделю и карточки погоды в крупнейших городах планеты.

Как это работает

  1. 1 Вы вводите название города — например, «Казань» или «Paris».
  2. 2 JavaScript через сервис геокодинга Open-Meteo находит координаты города.
  3. 3 По координатам запрашивается прогноз — и карточки на странице обновляются.

Технологии

  • 🧱HTML5 — семантическая разметка всех шести страниц сайта
  • 🎨CSS3 — фиолетовый градиент, карточки, адаптивная вёрстка и переменные цветов
  • ⚙️JavaScript (ES6+) — fetch-запросы, async/await, работа с DOM
  • 🌍Open-Meteo API — геокодинг городов и данные о погоде
  • ✅ESLint, Stylelint, html-validate — проверка качества кода
  • 🤖GitHub Actions + GitHub Pages — автодеплой при каждом push в main
